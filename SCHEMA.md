Entidades:
User -> autenticação e perfis
Recenseado -> pessoa principal do censo
Dependente -> grupo familiar
Beneficio -> benefício previdenciário
Contribuicao -> competência e valores
Documento -> documentação e conferência
Atendimento -> agenda/atendimento
Pendencia -> inconsistências e pendências
Auditoria -> trilha de ações
Importacao -> histórico de cargas
PendenciaImportada -> pendências da planilha funcional e reconciliação com o censo
LoginAttempt -> bloqueio temporário de tentativas de acesso
PastaArquivo -> hierarquia privada de diretórios
Arquivo -> metadados de arquivos armazenados em volume persistente

As consultas por localidade usam o código oficial do município do IBGE e agregam
localmente os registros funcionais por município/UF. Dados identificáveis não são
enviados à API pública do IBGE.
